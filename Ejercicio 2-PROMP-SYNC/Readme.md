#EJERCICIO PROMPT "CODE A TOY"

##Instrucciones

###Escribe un programa que solicite los siguientes datos de entrada:

- nombre
- nombre del puesto
- primer adjetivo
- segundo adjetivo
- primer alimento
- segundo alimento
- una emoción

###Luego, imprime el siguiente texto, reemplazando las palabras entre corchetes angulares (`<>`) con los datos proporcionados por el usuario:

### <nombre> comenzó hoy su primer curso de Generation. Se está formando para el puesto de <nombre del puesto>. Su grupo le pareció muy <primer adjetivo>, pero su instructor fue, al menos, <segundo adjetivo>. Para el almuerzo come <primer alimento> y <segundo alimento> mientras repasa sus apuntes. Se siente <una emoción>, pero está decidido a completar el curso.
