# 🔄 Ejercicios de Control de Flujo — Java

Este repositorio contiene una serie de ejercicios prácticos enfocados en dominar las estructuras de control de flujo en **Java**: bucles (`for`, `while`) y sentencias condicionales (`if`, `else`).

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java (JDK 17+)
* **Conceptos clave:** Bucles `for`, bucles `while`, condicionales `if-else`, clase `Scanner` para entrada de datos.

---

## 📌 Lista de Ejercicios

### 🔁 Ciclos `for`
1. **Contador 1 al 10:** Imprime los números del 1 al 10.
2. **Números pares (1 al 20):** Filtra e imprime los números pares del 1 al 20 usando una sentencia `if`.
3. **Tabla de multiplicar:** Muestra la tabla de multiplicar de un número ingresado por el usuario.
4. **Suma de elementos de un arreglo/lista:** Suma todos los elementos de un conjunto numérico dado.

### 🔄 Ciclos `while`
5. **Cuenta regresiva:** Muestra una cuenta regresiva del 10 al 1.
6. **Suma acumulativa:** Suma números ingresados por el usuario hasta que se introduce un número negativo.
7. **Juego de adivinanza:** Sistema donde el usuario intenta adivinar un número secreto con múltiples intentos.
8. **Cálculo de factorial:** Calcula el factorial ($n!$) de un número ingresado por el usuario.
9. **Secuencia de Fibonacci:** Genera la serie de Fibonacci hasta un límite determinado.

### 🔀 Sentencias `if`
10. **Positivo, negativo o cero:** Clasifica un número ingresado según su signo o si es cero.
11. **Par o impar:** Determina si un número es par o impar mediante el operador módulo (`%`).
12. **Año bisiesto:** Verifica si un año cumple con las condiciones para ser bisiesto.
13. **Comparador de números:** Determina cuál de dos números ingresados es el mayor.
