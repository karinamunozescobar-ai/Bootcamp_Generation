# 🚀 Bootcamp Generation Chile — Prácticas & Proyectos Web

Bienvenido/a a mi repositorio de aprendizaje y práctica del bootcamp de **Desarrollo Web Full Stack Java** en **Generation Chile**.

En este espacio organizo los ejercicios, desafíos y proyectos desarrollados durante el programa, enfocados en fortalecer mis habilidades en desarrollo Frontend y Backend, control de versiones y testing.

---

## 🛠️ Tecnologías & Herramientas

### Frontend
- **Lenguajes:** HTML5, CSS3, JavaScript (ES6+)
- **Librerías & Frameworks:** React, Bootstrap
- **Gestión de Paquetes:** NPM

### Backend & Bases de Datos
- **Lenguajes:** Java (JDK 17+)
- **Frameworks & Arquitectura:** Spring Boot, Spring MVC, Arquitectura MVC, APIs RESTful
- **Bases de Datos:** PostgreSQL, DBeaver, Consultas SQL

### Herramientas & Entornos
- **Control de Versiones:** Git, GitHub, GitHub Actions
- **Entornos de Desarrollo & Pruebas:** VS Code, IntelliJ IDEA, Postman, Bruno, Docker

## 💻 Cómo Ejecutar los Proyectos Localmente

### Clonar el repositorio:

#### Bash
- git clone https://github.com/tu-usuario/nombre-del-repositorio.git
- Navegar a la carpeta del proyecto específico:

#### Bash
- cd nombre-del-repositorio/modulo-deseado
- Para proyectos Frontend (React):

#### Bash
- npm install
- npm run dev

#### Para proyectos Backend (Java / Spring Boot):

- Abrir la carpeta del proyecto en IntelliJ IDEA o VS Code.

- Verificar la configuración de JDK 17+.

- Ejecutar la clase principal de la aplicación (Application.java).
